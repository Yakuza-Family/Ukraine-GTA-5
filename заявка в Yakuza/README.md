# Заявка до сім'ї Yakuza

Статична адаптивна форма збереження заявок у Google Sheets через Google Apps Script. Скрипт створює вказаний аркуш **«Заявки Yakuza»**, не змінюючи інші аркуші таблиці.

## Підключення таблиці

1. Відкрий [Apps Script](https://script.google.com/) під обліковим записом, який має право редагувати цільову таблицю.
2. Створи проєкт і заміни вміст `Code.gs` кодом із цього репозиторію.
3. У проєкті вибери **Deploy → New deployment → Web app**.
4. Установи **Execute as: Me** та **Who has access: Anyone**, після чого натисни **Deploy** і надай запитані дозволи. Публічний доступ потрібен, щоб відвідувачі форми могли її надіслати.
5. Скопіюй URL вебзастосунку, що закінчується на `/exec`, і встав його замість `PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE` у `app.js`.
6. Розмісти `index.html`, `styles.css` та `app.js` на вебхостингу. Файли мають бути доступні з одного каталогу.
7. Відкрий сторінку й надішли тестову заявку. У таблиці з'явиться аркуш **«Заявки Yakuza»** з рядком заголовків і тестовим записом.

Якщо оновиш `Code.gs` після розгортання, створи нову версію вебзастосунку через **Deploy → Manage deployments → Edit → New version → Deploy**.

## Дані у формі

Збираються ігровий нік, вік, Discord, доступний час онлайн, мотивація та необов'язкова інформація про попередні сім'ї. Не додавай до форми паролі чи іншу секретну інформацію. Доступ до заявок залежить від налаштувань доступу до Google-таблиці.
