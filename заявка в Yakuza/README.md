# Заявки до сім'ї Yakuza

Форма надсилає заявки до Google Sheets через розгорнутий Google Apps Script у `Code.gs`. Сторінка **«Таблиця заявок»** завантажує їх після серверної перевірки входу. Лишай саму Google-таблицю приватною.

URL розгорнутого вебзастосунку налаштований у кореневому `auth.js`. Якщо створиш нове розгортання, заміни там адресу на актуальну, що закінчується `/exec`.

Для налаштування або перевірки входу відкрий **Project Settings → Script Properties** у Apps Script: значення `APPLICATIONS_ADMIN_EMAIL` і `APPLICATIONS_ADMIN_PASSWORD` мають збігатися з поштою та паролем кабінету.

Якщо оновлюєш `Code.gs`, обов'язково опублікуй зміни: **Deploy → Manage deployments → Edit** (значок олівця) → **Version → New version → Deploy**. Редагування файлу саме по собі не оновлює вже опублікований вебзастосунок.

## Поля заявки

Форма зберігає час подання, ігровий нік, вік, Discord, час онлайн, мотивацію та попередні сім'ї. Не додавай паролі чи інші секретні дані до анкети.
