# Заявки до сім'ї Yakuza

На сайті є окрема сторінка **«Таблиця заявок»**. Форма надсилає заявки до серверного Apps Script, а він автоматично зберігає їх у приватному JSON-файлі на Google Drive власника скрипту. У колонці **«Рішення»** можна прийняти, відхилити заявку або повернути її на розгляд. Google Sheets для цього не використовується; файл сховища не потрібно створювати вручну чи відкривати публічно.

URL розгорнутого вебзастосунку налаштований у кореневому `auth.js`. Якщо створиш нове розгортання, заміни там адресу на актуальну, що закінчується `/exec`.

Посилання на фото та відео в розділі Media зберігаються спільно у приватному JSON-файлі Google Drive та завантажуються для всіх відвідувачів. Файли залишаються на сервісах, звідки взяті посилання; самі файли сайт не завантажує. Старі медіа, які були збережені лише в IndexedDB конкретного браузера, автоматично не переносяться до спільної медіатеки.

Для налаштування або перевірки входу відкрий **Project Settings → Script Properties** у Apps Script: значення `APPLICATIONS_ADMIN_EMAIL` і `APPLICATIONS_ADMIN_PASSWORD` мають збігатися з поштою та паролем кабінету.

Перед першим використанням сховища заявок вибери `setupApplicationsStorage` у списку функцій редактора Apps Script, натисни **Run** і підтверди запит на доступ до Google Drive. Це створить приватний файл для заявок у Drive власника скрипту. Файл зі спільними посиланнями Media створюється автоматично під час першого додавання посилання. Якщо змінюєш `Code.gs`, опублікуй зміни: **Deploy → Manage deployments → Edit** (значок олівця) → **Version → New version → Deploy**. Редагування файлу саме по собі не оновлює вже опублікований вебзастосунок.

## Поля заявки

Форма зберігає час подання, ігровий нік, вік, Discord, час онлайн, мотивацію та попередні сім'ї. Не додавай паролі чи інші секретні дані до анкети.
